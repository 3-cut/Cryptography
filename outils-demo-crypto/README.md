# Outils de démonstration pour la cryptographie

## Auteur
Projet réalisé par 3cut, l'interface graphique et certaines autres parties du code ont été réalisés à l'aide de l'IA Claude.

## Description

Outil pensé afin de faire découvrir la cryptographie à des collégiens, lycéens ou élèves de prépa.


## Compiler et lancer

```bash
make update
make exec
```

## Créer fichier .jar

```bash
make install
```

## Créer le serveur pour la version web

```bash
make web
```
